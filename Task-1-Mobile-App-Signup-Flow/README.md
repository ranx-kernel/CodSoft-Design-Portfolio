# ShieldPass – Mobile App Signup Flow

## Overview
ShieldPass is a cybersecurity-themed mobile authentication flow designed as part of my UI/UX Design Internship at CodSoft.

## Screens Included
- Splash Screen
- Welcome Screen
- Login Screen
- Success Screen

## Features
- Premium dark cybersecurity theme
- Face ID support
- Security success confirmation
- Interactive Figma prototype
